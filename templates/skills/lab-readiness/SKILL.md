# Проверка готовности лабораторного стенда

Использовать только для технической диагностики собственной учебной среды.
Это не исследовательский навык и не выполнение P2.

1. Выполнить через инструмент терминала:

   ```sh
   id -u
   pwd
   python --version
   test -d /opt/data && test -w /opt/data/workspace && echo WORKSPACE_OK
   ```

2. По реальному выводу проверить, что UID не равен `0`, рабочий каталог
   находится в `/opt/data/workspace`, а каталог доступен для записи.
3. Ответить по-русски: результат каждой проверки и оставшиеся ограничения.
4. Если инструмент недоступен или команда завершилась ошибкой, сообщить
   об этом. Не объявлять стенд готовым и не подставлять ожидаемый вывод.

Не читать `.env`, токены, ключи и журналы разговоров. Не устанавливать пакеты,
не изменять конфигурацию, не отправлять сообщения и не создавать cron-задачи.
